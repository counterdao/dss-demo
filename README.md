# dss-demo

## DSSDemo — frob an inc, get CTR

`DSSDemo` is a simple demo of a [dss](https://github.com/counterdao/dss) counter.

Any caller can `see` the current value, `hit` to increment, and `dip` to decrement.

Additionally, `hit`, and `dip` will distribute `CTR` governance token to
the caller if a sufficient balance remains in the `DSSToken` contract.

### View functions:
- `see`: Read the demo counter.

### Public functions:
- `hit`: Increment the demo counter.
- `dip`: Decrement the demo counter.
